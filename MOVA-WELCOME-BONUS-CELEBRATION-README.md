# MOVA welcome bonus

The welcome bonus is ₦9,100. Free members may see it in their wallet but cannot withdraw it. A free member who attempts to withdraw is shown the MOVA Premium upgrade prompt. Once Premium membership is confirmed, the welcome bonus can be selected as a withdrawal source, subject to the minimum withdrawal and available balance rules.

Withdrawal bank details are entered manually. The withdrawal page does not call Paystack for a bank directory or account-name lookup. The payout reviewer must independently check the bank details before sending funds.

The current withdrawal requests are kept in the app's local state and browser storage. They are not yet submitted to a shared admin queue or database. Do not treat this front-end-only flow as a completed production payout system.
