# MOVA favicon and search appearance assets

Added:
- Official MOVA symbol-based favicon in ICO and PNG sizes (16, 32, 48, 192, 512).
- Apple touch icon.
- Web app manifest.
- Social preview image using the supplied MOVA logo lockup unchanged.
- Updated title, description, theme color, Open Graph and X/Twitter metadata.
- Basic robots.txt allowing public pages to be crawled.

Important:
- Upload/deploy the site before requesting indexing.
- Google chooses when and whether to display a favicon in search results. It may take days or longer after recrawling; no website can guarantee the display.
- Google Search favicon guidance expects a crawlable, stable, square icon at least 48x48 pixels. MOVA includes 48x48 and larger assets.
- A real production-domain URL is still needed to add a canonical URL, absolute social preview URLs, a domain-specific sitemap, and Organization structured data. Do not substitute the Vercel dashboard URL for the public website URL.
